# Front door — Si Racha house

Replacing the front door of the house at 171/48 Moo 10, Bueng, Si Racha, Chonburi 20230 with a custom-size black aluminium sliding door.

Everything about the job is in this README. The quote request that goes to suppliers is in [2026-11-05-01-quote-request.md](2026-11-05-01-quote-request.md).

This folder is separate from the bathroom quote: nothing in the bathroom build reads it.

## The opening

| | |
|---|---|
| Width (structural opening) | 1720 mm |
| Height (structural opening) | 1980 mm |
| Floor at threshold | existing tiles — bottom track sits on them, no tiling work |
| Head | lintel (คานทับหลัง) — cannot be raised or cut |
| Sun | fully shaded |
| Existing | old door + inner steel sliding security door (6 bolts) — both removed by a local tradesman / neighbour |

**The problem:** stock sliding doors in Thailand are 204–205 cm high, and the factory custom web forms start at 205 cm. This opening is 198 cm, so every supplier must confirm in writing that they can make it below 205 cm.
